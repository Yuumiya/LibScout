What LibScout Is

LibScout is a code search tool for small or recently updated libraries. Instead of indexing only docs, it indexes real usage snippets from public repositories.

For Developers

Search real snippets using symbol/call/import filters and code context.

For AI

Use the same index through the HTTP MCP-compatible endpoint.

Why Tree-sitter Matters

  • We parse files into a Concrete Syntax Tree, not plain text.
  • We extract function and class level chunks instead of arbitrary line windows.
  • Each chunk stores structural metadata: symbol, calls, imports, scope type, line span.
  • Search can rank exact symbols and call shapes before falling back to generic similarity.
The core product value is finding usable implementation patterns quickly, with structural signals (symbols, calls, imports, scope) driving ranking.

Takeaways

  1. Indexing real code usage is more useful than relying only on docs.
  2. tree-sitter gives better snippet boundaries and better retrieval signals.
  3. Search quality comes from balancing structure-first matching with practical ranking.
  4. This architecture already supports both developers and MCP clients from one index.
